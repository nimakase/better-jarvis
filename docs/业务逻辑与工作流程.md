## 1. 生意是什么

- **公司(CCL,"Your Excess Inventory Partner")做的是电子元件的 excess/surplus 收购与经销**:别的公司有多余、积压的板级电子元件(board-level components),CCL 收过来再转卖。〔据我理解:你们在**买方/收购侧**,客户 = 手上有 excess 要出的公司。〕
- **你(Ned)的角色**:Account Manager / 采购(Purchasing)。你负责一批账户(公司),去开发、评估他们的 excess、拿下、维护关系。〔据我理解〕
- 你能做/不能做的料:能做的是**板级电子元件**;像**线材、塑料件、五金、成品(耳机/充电宝/线缆)**这类不是你们的业务。〔据我理解——这条直接决定一个 list 是"好料"还是"垃圾料"〕

## 2. 一个账户的一生

从一家陌生公司到成交或放弃,大致这条线:

1. **陌生公司**(还没往来)→ 进**开发流(Prospecting)**。
2. 你给它发 **sequence**(冷邮件)想撬开对话。
3. 对方可能:**不回**(继续发)/ **回信**(看回的是什么)/ **直接发来 excess list**。
4. 拿到 list → 你评估料好不好、量够不够 → **建 deal**。
5. deal 结果:**won**(成交,CCL 收了他们的 excess)/ **lost**(没谈成:价格、时机、别的)。
6. 有过 deal 的(尤其 won)→ 转**维护流(Core)**,当好客户长期维护,等他们下次又有 excess。
7. 三轮 sequence 都没撬开、又没潜力的 → **放弃**,让它自然流走。

〔据我理解:won 的含义是"他们的 list 确实是你们能做的料、且谈成了",所以 won 客户 = 真好客户。〕

## 3. 两层分类(核心心智,别揉一起)

- **第一层:HubSpot Account Type = Core / Prospecting** —— 这是**公司政策的开关 + 你的手动控制**,决定这户会不会被公司的 time-decay 自动回收。**你手动设,贾维斯只读不写。**
  - Core:受保护、永不 decay、上限 450。
  - Prospecting:开发池、6 个月无活动会被系统退回 No owner、上限 550。
- **第二层:贾维斯价值分层** —— 贾维斯替你算的**优先级判断**,落在 Bitable / 私有 view 里,不写回 HubSpot。
  - Core 内:**T0**(多个 won,长期伙伴)/ **T1**(1~2 won,低频出货)/ **活跃单**(有进行中 deal)/ **T2**(lost 但料好、可期)。
  - Prospecting 内:未开发 / 开发中 / 待处理(换人或放弃)/ 已回复。
- **两者关系**:Type 管"保不保护",分层管"多上心、怎么动"。
- **保护性 Core**:你有时会把**没 deal、按逻辑本该 Prospecting 的账户手动标 Core 来保护它**(不想让它被 decay 收走)。这是**你的合法操作**,贾维斯要尊重:按你设的 Type 走,不自动降级,只在你没批注过时温和问一句"确认要保护?"。〔据我理解——这正是你要的那种手动干预〕

## 4. Prospecting:冷开发流

- **sequence = 你自己写自己发**:一整套 **3 轮,每轮 3 封同标题连发,轮与轮间隔约 2 个月**。〔已确认〕
- **判定极简**(不数联系人/轮次细节到状态):
  - 没发过 → **未开发**。
  - 还在跑(三轮没完)、上封在 2 月内 → **开发中**;上封超 2 月 → **该发下一轮**(提醒你)。
  - 三轮跑完还没回 → **待处理**(你定:换人重开 / 放弃)。
  - 有真回信 → **已回复**(最高优先)。
- **换联系人**:三轮无果但公司有潜力 → 换个 contact 重开一轮。**换不换你定**,贾维斯只把"已试过谁/还没试谁 + 岗位"摊给你参考。
- **放弃 = 什么都不做**:停止发,让 HubSpot time-decay 自己在 6 个月无活动后把它退回 No owner。不用手动标 dead。公司还会在你停手约 4.5 个月后**自动补一轮**(你没 opt-out),白送一次机会;钓到回复就活、钓不到照样流走。

## 5. 回复处理(6 类)

对方回信可能是任何东西,**"是不是真回复、是什么"由贾维斯 LLM 判**(Breeze 只把回信原文抓回来,不判)。自动回复(out-of-office)当**没回复**处理,不算真回信。真回复归 6 类:

| 类别 | 含义 | 动作 |
|---|---|---|
| 发来可做的料 list | = 准成交 | 你建 deal、转 Core |
| 发来不可做的 list(成品/线材) | 垃圾料 | 记 note、标 list 质量差 |
| 有兴趣但当下没货(暂无货/卡NDA/已有渠道) | 以后再说 | 建带唤醒日的跟进 Task |
| 明确不做 | 硬拒 | 停 sequence、考虑释放 |
| 转介给别人 | 换人 | 去联系新 contact |
| 纯客套 | 无实质 | 不打扰、存档 |

## 6. Core:维护流(绝不冷开发)

- Core 永不 decay,所以维护是**纯关系保温**(公司层零压力,唯一硬要求是拿下账户后 2 周内补 Contact 地址)。
- 维护间隔按分层:**T0 ~45 天 / T1 ~90 天 / T2 ~60 天**没 touch 就提醒你联系。〔起始值,可改〕
- **list 质量**是判 lost-无-won 账户去向的关键(好→T2 值得回访;差→不占 Core)。这条**要你判**(据料对不对、量够不够),你写在 Bitable 的 list质量列,贾维斯读回来用。
- **Core·冷处理**:低质但你想留着的(如线材塑料头那类),手动钉休眠,搁置有机会再看。

## 7. deal 流 & list 质量

- **list → deal → won/lost**:客户发来 excess list,你评估后建 deal;won=收下了,lost=没谈成。
- **won 数**HubSpot 没有原生列 → 贾维斯问 Breeze 数(供分 T0/T1)。
- **list 质量(好/弱/差)**是判断题、要懂"你们能做什么料",HubSpot 里没有 → **你在 Bitable 手写**,贾维斯读回来喂分层。

## 8. 公司政策约束(Time-Decay Account Cap,2026-05 生效)

- 每人上限 1000 = **450 Core(保护、永不 decay)+ 550 Prospecting(6 个月无 qualifying activity → 退回 No owner)**。
- **qualifying activity**(重置 6 个月时钟)= 电话/1:1 邮件/sequence 邮件/会议/note/完成的 task/对话/关联 deal 的活动 —— 以 HubSpot 的 Last Activity Date 为准。
- 上限是天花板不是 KPI;只持有 Core、不填满 Prospecting 也 OK。
- 放弃账户释放到 No owner 是正当选择,好过占着不做。

## 9. 日常怎么干 + 你会看到什么

- **HubSpot 段视图 = 你动手的地方**:贾维斯把各段账户名(名单法)写进对应 view;你在 HubSpot 里按 view 干活——enroll sequence、批量操作、跟进已回复、维护 core。(sequence/批量只能在 HubSpot 干。)
- **Bitable 驾驶舱 = 你决策 + 批注的地方**:全账户一行,贾维斯写状态列,你手写 **list质量 / 处置** 两列;打开就看最新态。
- **夜报**:每晚发生了什么、出了哪些提议、缺名/异常/FYI。

## 10. 你和贾维斯的分工 + 沟通

- **分工**:贾维斯 = 观察(读 HubSpot/Breeze/Bitable)+ 算(分层/decay/回复判定)+ 摆台面(维护 view、写 Bitable、拟提议、夜报);你 = 决策 + 手动写(设 Type、发信、建/输 deal、释放、回复)。
- **指纹回路**:你在 HubSpot 的动作留下指纹(Type/deal/活动/owner 变化)→ 下一晚重读被看见,贾维斯据此重算、退休过时建议,不跟你对着干、不覆盖你。
- **处置框 = 你和贾维斯的通用沟通渠道(秘书逻辑)**:你在 Bitable 处置格里随手写自然语言,贾维斯 LLM 读懂意图并做**安全的**贾维斯侧动作(保护/换人/暂停/放弃/标质量/已处理/纯备注),把整理后的一句话回写给你看,并记住"懂了、不再重复问"。**绝不因一句 note 去动 HubSpot 的 Type/owner 或做不可逆的事**——涉及外部的都走提议/你手动。

## 11. 关键参数(旋钮,可改)

- sequence:3 轮 × 3 封同标题 / 轮间隔 **2 月**;开发中判定 **ACTIVE = 上封 ≤2 月**。
- Core 维护间隔:T0 **45** / T1 **90** / T2 **60** 天。
- 公司 decay:**4 个月 2 周**无活动触发 → 约 6 个月退回 No owner。
- T0 门槛:won ≥ **3**(多个);T1 = won 1~2。
